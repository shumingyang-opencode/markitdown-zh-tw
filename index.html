MarkItDown 繁體中文教學站

把整個 repo（程式碼 · 轉換器 · CLI · 外掛 · MCP · Azure）做成中英對照的解說
MarkItDown 是微軟 AutoGen 團隊出品的開源 Python 工具：用一個指令把 PDF、PowerPoint、Word、Excel、圖片、音訊、HTML、CSV、ZIP、YouTube、EPUB 等檔案轉成 Markdown，供 LLM 與文字分析管線直接使用—— 保留標題、清單、表格、連結等文件結構。
🕸️ 概念地圖 Concept Map converter、priority、StreamInfo、magika、accepts/convert、plugin、entry-point——一張圖看懂轉換管線的所有核心概念。 🧗 學習路線 Learning Path 從安裝到讀源碼的分層路線：L0 裝好、L1 跑起來、L2 玩轉格式、L3 讀原理、L4 讀源碼。 📦 Install Guide 安裝指南 pip extras 表、uv、conda、source、Docker、markitdown-mcp / markitdown-ocr、疑難排解。 📚 文件教學 Documentation 翻譯並解說官方文件：運作原理、架構、轉換器總覽、CLI、Python API、外掛、MCP、Azure、安全。 🧩 程式碼對照 Code Walkthrough MarkItDown 類別、CLI、converter 介面、Office/PDF/Web/Media 轉換器、外掛與 MCP 套件逐函數講解。 🎮 Worked Examples 實作案例 11 種格式的真實轉換輸出（本站實跑），外加用 graphify 掃描 MarkItDown 自己的互動知識圖譜。

  • 整合：Azure Document Intelligence、Azure Content Understanding、LLM Vision（圖片描述/OCR）、Docker、MCP（STDIO/HTTP/SSE）
