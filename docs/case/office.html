案例：Office 轉換

DOCX / XLSX / PPTX——真實工具輸出，本站實跑
markitdown 0.1.7 · 對齊 fd239d5 · 輸入樣本由 scripts/generate-samples.py 產生

1. Word（sample-report.docx）

輸入含：標題、段落、項目符號、3×3 表格。轉換後標題保留為 #/##、 項目符號變 *、表格變 Markdown 表格。注意表格第一行「標題列」被當成表頭以外的資料列。

MarkItDown 測試文件

這是一份用來示範 MarkItDown 轉換的 Word 文件。包含標題、段落、項目符號與表格，轉換後應保留結構。

# 第一個章節

段落文字：markitdown 會保留 heading、list 與 table 等結構。

## 功能清單

* PDF 轉換
* Word 轉換
* Excel 轉換
* 簡報轉換
* 圖片/音訊

## 版本比較表

|  |  |  |
| --- | --- | --- |
| 功能 | markitdown | textract |
| PDF | ✅ | ✅ |
| DOCX | ✅ | ✅ |
markitdown worked/conversions/office/sample-report.docx -o worked/conversions/office/sample-report.md

2. Excel（sales-data.xlsx）

每個工作表輸出 ## 工作表名 + Markdown 表格。觀察點：合併列（Total）與 「註：」那行被併入表格且多出 NaN——這是 pandas 讀整張表的誠實結果。

## Sales
| Region | Product | Units | Revenue |
| --- | --- | --- | --- |
| North | Widget | 120.0 | 2400.0 |
| North | Gadget | 80.0 | 3200.0 |
| South | Widget | 150.0 | 3000.0 |
| South | Gadget | 60.0 | 2400.0 |
| East | Widget | 90.0 | 1800.0 |
| Total | NaN | 500.0 | 12800.0 |
| 註：此為樣本資料，用於示範 Excel → Markdown 的表格保留。| NaN | NaN | NaN |
markitdown worked/conversions/office/sales-data.xlsx -o worked/conversions/office/sales-data.md

3. PowerPoint（pitch-deck.pptx）

每張投影片輸出 <!-- Slide number: N --> 註解分頁 + 標題 + 項目 + 表格。 方便追蹤「這一段來自第幾頁」。

<!-- Slide number: 1 -->
# MarkItDown 簡報範例
示範 PowerPoint 轉 Markdown
作者：markitdown-zh-tw

<!-- Slide number: 2 -->
# 為什麼用 Markdown？
對 LLM 友善
token 效率高
保留文件結構

<!-- Slide number: 3 -->
# 支援格式一覽
| 格式 | 狀態 |
| --- | --- |
| PDF | ✅ |
| DOCX | ✅ |
| XLSX | ✅ |
markitdown worked/conversions/office/pitch-deck.pptx -o worked/conversions/office/pitch-deck.md
本站觀察：Office 三種格式的輸出品質都不錯——標題、清單、表格都能保留。 實務上若要更高保真（例如複雜 Word 數學公式），DOCX 家族另有 converter_utils/docx 的 OMML→LaTeX 前處理（見程式碼對照）。

重現方式

# 產生樣本檔（本機需 python-docx / openpyxl / python-pptx）
python scripts/generate-samples.py

# 轉換
markitdown worked/conversions/office/sample-report.docx -o worked/conversions/office/sample-report.md
markitdown worked/conversions/office/sales-data.xlsx  -o worked/conversions/office/sales-data.md
markitdown worked/conversions/office/pitch-deck.pptx  -o worked/conversions/office/pitch-deck.md
