概念解說

程式碼對照區是「文件 → 源碼」的橋樑。每個收縮塊對應一個 Python 模組或類別， 提供函式簽名、中文用途說明、以及關鍵邏輯的逐行講解。 建議搭配運作原理和架構總覽一起閱讀。

核心入口是 MarkItDown 類別（core.html），它串連了 CLI（cli.html）、 converter 協定（base.html）、22 個內建轉換器（converters/）、 以及外掛與 MCP 套件。

常見錯誤與除錯

找不到對應的源碼？
確認你閱讀的頁面與 markitdown 版本一致。本站對齊上游 fd239d5（v0.1.7）。 版本不同可能有函式名或參數差異。
建議閱讀順序：
base.html（協定）→ core.html（入口）→ converters.html（概覽）→ 特定格式頁。

練習與驗收

  1. 在 core.html 找到 register_converter() 方法，理解它如何將 converter 插入排序清單。
  2. 在 base.html 閱讀 DocumentConverter 的抽象方法定義，寫一個最小的自訂 converter。
  3. 選一個內建 converter（如 CsvConverter），在源碼中找到它的 accepts() 和 convert() 實作。
