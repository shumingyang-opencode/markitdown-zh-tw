Docker

不污染本機 Python 環境，一行指令把檔案丟進容器轉換

建映像與使用

# 從 repo 根目錄（含 Dockerfile）建映像
docker build -t markitdown:latest .

# stdin 管道轉換
docker run --rm -i markitdown:latest < ~/your-file.pdf > output.md

docker 版本非常適合：不想在本機裝 Python 依賴、或需要乾淨隔離（配合外掛/多版本）的場景。

markitdown-mcp 的 Docker 用法

# 建映像
docker build -t markitdown-mcp:latest .

# 啟動（遠端 URI 即可，本機檔案需掛載）
docker run -it --rm markitdown-mcp:latest

# 掛載本機目錄：容器內以 /workdir 存取
docker run -it --rm -v /home/user/data:/workdir markitdown-mcp:latest

搭配 Claude Desktop

{
  "mcpServers": {
    "markitdown": {
      "command": "docker",
      "args": ["run", "--rm", "-i", "-v", "/home/user/data:/workdir", "markitdown-mcp:latest"]
    }
  }
}
安全提示：容器預設無法存取本機檔案；掛載目錄等於把該路徑開放給容器內程序。 只掛載需要的目錄，並注意 markitdown-mcp 無認證機制。
