外掛系統

MarkItDown 用 Python entry-point 讓第三方擴充「安裝即註冊」，預設關閉

運作方式

  1. 外掛套件在 pyproject.toml 宣告 entry-point：[project.entry-points."markitdown.plugin"]。
  2. 套件匯出 __plugin_interface_version__ 與 register_converters(markitdown, **kwargs)。
  3. 每次建立 MarkItDown 實例時，若 enable_plugins=True（或 CLI --use-plugins）， 會 entry_points(group="markitdown.plugin") 載入全部已安裝外掛，呼叫 register_converters()。
  4. 外掛可用 register_converter(converter, priority=...) 在任何優先級插入 converter——包括搶在內建 converter 之前。

外掛預設關閉

# 列出已安裝外掛
markitdown --list-plugins

# 使用外掛
markitdown --use-plugins path-to-file.pdf

# Python API
md = MarkItDown(enable_plugins=True)
result = md.convert("path-to-file.rtf")
注意：外掛載入失敗（entry_point.load() 拋例外）不會中斷， 只會 warn() 並跳過——所以裝了外掛但沒生效時，先檢查 --list-plugins。

官方外掛：markitdown-ocr

用 LLM Vision 抽取 PDF、DOCX、PPTX、XLSX 中「內嵌圖片」的文字（OCR）， 不需要新 ML 函式庫——沿用核心既有的 llm_client / llm_model 模式。

pip install markitdown-ocr
pip install openai

markitdown document.pdf --use-plugins --llm-client openai --llm-model gpt-4o

重點行為：

  • 四個 OCR 增強 converter 以 priority -1.0 註冊——在內建（0.0）之前。
  • 掃描版 PDF（無文字層）自動整頁渲染 300 DPI 送 LLM。
  • OCR 區塊包成 *[Image OCR]...<文字>[End OCR]*，就地插入不破壞文件流程。
  • 沒有 llm_client 時外掛仍載入但「靜默略過」，退回內建 converter。

以 RtfConverter 為例，三步完成：

# 1. 實作 DocumentConverter
class RtfConverter(DocumentConverter):
    def accepts(self, file_stream, stream_info, **kwargs) -> bool:
        ...  # 判斷是不是 RTF
    def convert(self, file_stream, stream_info, **kwargs) -> DocumentConverterResult:
        ...  # 轉成 Markdown

# 2. 匯出外掛協定
__plugin_interface_version__ = 1

def register_converters(markitdown: MarkItDown, **kwargs):
    markitdown.register_converter(RtfConverter())

# 3. pyproject.toml 宣告 entry-point

概念解說

MarkItDown 的外掛系統基於 Python entry-point 機制。 外掛套件在 pyproject.toml 宣告 [project.entry-points."markitdown.plugin"]， 匯出 register_converters(markitdown, **kwargs) 函數。 每次建立 MarkItDown(enable_plugins=True) 時，會自動載入所有已安裝外掛。

外掛可以在任何 priority 註冊 converter——包括負值（搶在內建之前）或正值（兜底之後）。 這讓 markitdown-ocr 能以 priority -1.0 在內建 PDF/DOCX converter 之前攔截，注入 OCR 增強。

實際操作 Worked Example

步驟 1：安裝官方 OCR 外掛

pip install markitdown-ocr openai

# 確認外掛已安裝
markitdown --list-plugins

步驟 2：用外掛轉換含圖片的 PDF

# 啟用外掛 + LLM 圖片描述
markitdown document.pdf --use-plugins -o out.md

# Python API
from markitdown import MarkItDown
from openai import OpenAI
md = MarkItDown(enable_plugins=True, llm_client=OpenAI(), llm_model="gpt-4o")
result = md.convert("document.pdf")

常見錯誤與除錯

外掛裝了但沒生效
執行 markitdown --list-plugins 確認外掛是否被偵測。若不在清單中，檢查 pyproject.toml 的 entry-point 宣告。
OCR 外掛靜默略過
沒有 llm_client 時，OCR 外掛仍載入但「靜默略過」——退回內建 converter。不會報錯，但也沒有 OCR 增強。

練習與驗收

  1. 安裝 markitdown-sample-plugin，用 --list-plugins 確認。
  2. 閱讀 sample-plugin 的 register_converters()，理解外掛如何插入 converter。
  3. 故意移除 entry-point 宣告，觀察外掛消失的行為。
