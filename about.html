本站是什麼

本站是 microsoft/markitdown 的 非官方繁體中文教學站。目標是把整個 repo（程式碼、轉換器、CLI、外掛、MCP、 Azure 整合、測試）做成「中英對照」的策展式解說——不逐檔鏡像，而是挑「值得教學」的內容深入講解。

方法

  • 文件頁：中文口語解說為主文，英文原文以可展開 <details> 保留。
  • 程式碼頁：每個函數一個收縮塊（signature + 中文用途 + 關鍵邏輯），核心函數附逐行中文註解。
  • 實作案例：所有數字與輸出都是本站以本機工具實跑取得，不是示意圖。
  • 版本釘選：內容對齊上游 main @ fd239d5（v0.1.7），可追溯。

我們怎麼跑的

  1. 建立 uv 虛擬環境，從對齊 commit 的源碼安裝 markitdown[all]（0.1.7）。
  2. 用 scripts/generate-samples.py 產生各格式樣本輸入檔（python-docx / openpyxl / python-pptx / reportlab / Pillow / piexif）。
  3. 對每種格式執行 markitdown <file> -o out.md，把真實輸出收進 worked/conversions/。
  4. 用 markitdown 轉 markitdown 自己（README / pyproject.toml / Dockerfile / GitHub 頁 / PyPI 頁）作 dogfooding。
  5. 用 graphify 0.9.40（--code-only，純本機 AST）掃描源碼，產出互動知識圖譜與 GRAPH_REPORT。
  6. 把 graph.html 中文化成 graph-zh.html（UI 字串替換，節點標籤保留英文）。
